# Helldivers 2 攻略站项目说明

本项目用于构建一个面向 `Helldivers 2` 玩家 的攻略站首页与后续内容页。

## 请先阅读
在修改代码前，请先阅读：
- `project_brief.md`
- `steam_trend_analysis.md`

## 项目目标
- 提供新手入门入口
- 提供当前版本强势武器 / 配装 / 战术
- 提供任务与阵营打法
- 提供版本更新与社区内容导览

## 首页定位
首页是“战术入口页”，不是普通文章列表页。

## 当前 MVP 页面
- `helldivers2_mvp.html`

## 设计原则
- 版本感强
- 入口清晰
- 标题结果导向
- 内容结构模块化
- 视觉风格偏战术站 / 信息中心
